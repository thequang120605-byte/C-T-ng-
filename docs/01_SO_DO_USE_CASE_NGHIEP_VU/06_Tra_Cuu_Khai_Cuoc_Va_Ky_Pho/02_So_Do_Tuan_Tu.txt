boundary "Kho Kỳ phổ\nDanh thủ Đương đại" as BookServ
database "Cơ sở dữ liệu\nTừ điển Khai cuộc" as DB

== 1. TÌM KIẾM THẾ TRẬN KHAI CUỘC ==
Player -> UI: Nhập tên thế trận hoặc đi thử nước cờ khởi đầu
UI -> Ctrl: Yêu cầu tra cứu dữ liệu thế cờ
Ctrl -> DB: Truy vấn cây dữ liệu biến thể khai cuộc
DB --> Ctrl: Trả về danh sách nước biến và tỷ lệ thắng
Ctrl --> UI: Hiển thị các nhánh biến thể và thống kê xác suất

== 2. TRUY VẤN VÁN ĐẤU THỰC CHIẾN CỦA DANH THỦ ==
Player -> UI: Yêu cầu xem các ván đấu thực tế của danh thủ
UI -> Ctrl: Yêu cầu danh sách ván đấu thực chiến
Ctrl -> BookServ: Truy vấn kho kỳ phổ danh thủ áp dụng thế trận
BookServ --> Ctrl: Trả về danh sách ván cờ đỉnh cao tương ứng
Ctrl --> UI: Hiển thị danh sách ván cờ mẫu

== 3. PHÁT LẠI VÀ THAO TÁC NƯỚC ĐI DANH THỦ ==
Player -> UI: Chọn một ván đấu và nhấp chuyển nước đi
UI -> Ctrl: Yêu cầu dữ liệu nước cờ chi tiết của ván cờ
Ctrl --> UI: Cập nhật thế cờ từng bước trên bàn cờ trực quan
@enduml
