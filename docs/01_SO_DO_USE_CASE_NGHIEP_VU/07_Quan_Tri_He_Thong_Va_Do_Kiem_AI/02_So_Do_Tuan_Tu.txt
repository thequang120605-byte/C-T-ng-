control "Xử lý Quản trị\n& Điều phối Đo kiểm" as Ctrl
boundary "Động cơ Đo kiểm\nHiệu năng AI (Benchmark)" as BenchServ
database "Cơ sở dữ liệu\nQuản trị & Nhật ký" as DB

== 1. QUẢN TRỊ TÀI KHOẢN VÀ DỮ LIỆU HỆ THỐNG ==
Admin -> UI: Yêu cầu cập nhật quyền hoặc khóa/mở tài khoản
UI -> Ctrl: Gửi thông tin thay đổi trạng thái người dùng
Ctrl -> DB: Cập nhật trạng thái vào cơ sở dữ liệu người dùng
DB --> Ctrl: Xác nhận trạng thái đã được cập nhật thành công
Ctrl --> UI: Hiển thị thông báo hoàn tất trên bảng quản trị

== 2. THIẾT LẬP VÀ KÍCH HOẠT ĐO KIỂM HIỆU NĂNG AI ==
Admin -> UI: Lựa chọn bộ thế cờ FEN và thiết lập độ sâu kiểm thử
UI -> Ctrl: Yêu cầu chạy tiến trình đo kiểm hiệu năng AI (Benchmark)
Ctrl -> BenchServ: Kích hoạt bộ kiểm thử tính toán theo độ sâu
loop Lặp duyệt qua các thế cờ kiểm thử
    BenchServ -> BenchServ: Thực thi thuật toán Minimax và Alpha-Beta
    BenchServ -> BenchServ: Ghi nhận số nút duyệt (Nodes) và thời gian (ms)
end

== 3. TỔNG HỢP VÀ BÁO CÁO KẾT QUẢ ĐO KIỂM ==
BenchServ --> Ctrl: Trả về kết quả tốc độ duyệt (NPS) và tỷ lệ cắt tỉa
Ctrl -> DB: Lưu nhật ký kết quả đo kiểm hiệu năng vào hệ thống
DB --> Ctrl: Xác nhận lưu trữ nhật ký thành công
Ctrl --> UI: Hiển thị bảng số liệu và đồ thị đo kiểm hiệu năng AI
