== 1. KHỞI TẠO VÀ THIẾT LẬP VÁN ĐẤU ==
Player -> UI: Lựa chọn chế độ thi đấu (PvP / PvE)
UI -> Ctrl: Yêu cầu khởi tạo phòng đấu mới
Ctrl -> DB: Tạo bản ghi ván đấu và thiết lập thời gian
DB --> Ctrl: Xác nhận thông tin phòng đấu thành công
Ctrl --> UI: Trả về trạng thái bàn cờ ban đầu

== 2. THỰC HIỆN NƯỚC ĐI VÀ ĐỐI KHÁNG ==
Player -> UI: Thực hiện nước đi trên bàn cờ trực quan
UI -> Ctrl: Gửi thông tin tọa độ nước cờ
Ctrl -> DB: Kiểm tra luật cờ và lưu nước đi hợp lệ
alt Chế độ đấu máy (PvE)
    Ctrl -> AI: Yêu cầu AI tính toán nước cờ tối ưu
    AI --> Ctrl: Trả về nước phản hồi tốt nhất
    Ctrl -> DB: Lưu nước đi của máy vào biên bản
end
Ctrl --> UI: Đồng bộ trạng thái bàn cờ thời gian thực

== 3. KẾT THÚC VÁN ĐẤU VÀ TÍNH ĐIỂM ELO ==
Player -> UI: Xác nhận kết thúc (Chiếu bí / Cầu hòa / Đầu hàng)
UI -> Ctrl: Gửi tín hiệu hoàn tất ván đấu
Ctrl -> DB: Cập nhật kết quả chung cuộc và tính biến động Elo
DB --> Ctrl: Xác nhận cập nhật thành công
Ctrl --> UI: Hiển thị bảng tổng kết ván cờ và điểm số mới
@enduml
