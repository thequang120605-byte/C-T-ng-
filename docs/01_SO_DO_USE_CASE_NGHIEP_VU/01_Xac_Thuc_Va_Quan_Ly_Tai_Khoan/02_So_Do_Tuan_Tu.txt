boundary "Dịch vụ\nEmail OTP" as Mail
database "Cơ sở dữ liệu\nNgười dùng & Elo" as DB

== 1. ĐĂNG KÝ VÀ XÁC THỰC OTP ==
User -> UI: Nhập Email, Tên hiển thị, Mật khẩu
UI -> Ctrl: Yêu cầu đăng ký tài khoản mới
Ctrl -> Mail: Yêu cầu tạo và gửi mã xác thực OTP
Mail --> User: Chuyển phát mã xác thực OTP đến Email người dùng
User -> UI: Nhập mã xác nhận OTP
UI -> Ctrl: Gửi mã OTP xác nhận
Ctrl -> DB: Kiểm tra hợp lệ và lưu tài khoản mới

== 2. ĐĂNG NHẬP VÀ PHÂN QUYỀN ==
User -> UI: Nhập tài khoản và mật khẩu
UI -> Ctrl: Gửi thông tin đăng nhập
Ctrl -> DB: Đối chiếu thông tin và kiểm tra trạng thái
Ctrl --> UI: Cấp quyền truy cập và phân bổ vai trò

== 3. TRUY VẤN HỒ SƠ VÀ LỊCH SỬ ELO ==
User -> UI: Yêu cầu xem hồ sơ cá nhân
UI -> Ctrl: Yêu cầu tải dữ liệu kỳ thủ
Ctrl -> DB: Truy vấn thông tin và biến động điểm Elo
DB --> Ctrl: Trả về dữ liệu chi tiết
Ctrl --> UI: Hiển thị hồ sơ và đồ thị lịch sử Elo
@enduml
