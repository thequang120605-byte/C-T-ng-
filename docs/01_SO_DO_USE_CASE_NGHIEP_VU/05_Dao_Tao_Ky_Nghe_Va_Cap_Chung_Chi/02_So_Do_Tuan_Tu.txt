== 1. HỌC LÝ THUYẾT VÀ TƯƠNG TÁC THẾ CỜ ==
Player -> UI: Lựa chọn bài học trong chuyên đề đào tạo
UI -> Ctrl: Yêu cầu tải giáo trình và sơ đồ thế cờ mẫu
Ctrl -> DB: Truy vấn nội dung bài giảng chuyên sâu
DB --> Ctrl: Trả về tài liệu lý thuyết và thế trận mẫu
Ctrl --> UI: Trình bày nội dung học tập tương tác

== 2. THI SÁT HẠCH TRẮC NGHIỆM VÀ ĐÁNH GIÁ ==
Player -> UI: Bắt đầu bài thi sát hạch và nộp câu trả lời
UI -> Ctrl: Gửi toàn bộ đáp án bài thi của học viên
Ctrl -> CertServ: Chuyển dữ liệu chấm điểm tự động
CertServ --> Ctrl: Trả về tổng điểm và kết quả Đạt / Không đạt

== 3. CẤP CHỨNG CHỈ ĐIỆN TỬ VÀ LƯU HỒ SƠ ==
alt Kết quả bài thi đạt chuẩn (>= 80%)
    Ctrl -> CertServ: Yêu cầu tạo mã chứng chỉ điện tử CERT-CT
    CertServ --> Ctrl: Cung cấp mã định danh chứng chỉ duy nhất
    Ctrl -> DB: Lưu kết quả thi và cấp chứng chỉ vào hồ sơ
    DB --> Ctrl: Xác nhận cập nhật chứng chỉ thành công
end
Ctrl --> UI: Hiển thị chứng chỉ điện tử và cho phép tải về
