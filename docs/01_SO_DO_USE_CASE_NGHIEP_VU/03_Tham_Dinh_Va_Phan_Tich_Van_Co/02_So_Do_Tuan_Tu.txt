== 1. YÊU CẦU THẨM ĐỊNH VÁN ĐẤU ==
Player -> UI: Chọn ván cờ cần thẩm định từ lịch sử
UI -> Ctrl: Yêu cầu thẩm định dữ liệu ván cờ
Ctrl -> DB: Truy vấn thông tin ván đấu và chuỗi nước đi
DB --> Ctrl: Trả về biên bản ván cờ chi tiết

== 2. PHÂN TÍCH THẾ CỜ VÀ NHẬN DIỆN SAI LẦM ==
alt Chưa có báo cáo thẩm định trước đó
    loop Lặp duyệt qua từng nước cờ trong ván
        Ctrl -> AI: Yêu cầu lượng giá thế cờ và tìm nước tối ưu
        AI --> Ctrl: Trả về điểm Eval, tỷ lệ thắng và nước gợi ý
    end
    Ctrl -> DB: Lưu kết quả phân tích và thống kê sai sót
end

== 3. TRÌNH DIỄN BÁO CÁO VÀ GỢI Ý NƯỚC TỐI ƯU ==
Ctrl --> UI: Trả về dữ liệu thẩm định và đồ thị thế trận
Player -> UI: Nhấp chọn nước cờ cụ thể trên biểu đồ
UI -> Ctrl: Yêu cầu chi tiết nước đi thay thế
Ctrl --> UI: Hiển thị bàn cờ phân tích và mũi tên gợi ý
@enduml
